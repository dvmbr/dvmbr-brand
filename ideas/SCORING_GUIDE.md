# Scoring Guide

## Principle

- Don't score the idea.
- Score the value it would create for users.

| Score | Useful | Delightful | Beautiful |
| ------: | --------- | ------------ | ----------- |
| 1 | 거의 도움 안 됨 | 감정적 가치 거의 없음 | 경험적 가치 거의 없음 |
| 2 | 조금 편해짐 | 약간 재미있음 | 평범한 경험 |
| 3 | 분명히 시간을 아껴줌 | 사용하면 기분이 좋아짐 | 보기 좋고 사용성이 좋음 |
| 4 | 자주 사용할 만큼 유용함 | 다른 사람에게 추천하고 싶음 | 완성도가 높고 기억에 남음 |
| 5 | 없어지면 불편할 정도 | 사람들에게 웃음이나 큰 만족을 줌 | 감탄할 정도의 경험을 제공 |
