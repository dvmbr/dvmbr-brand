# dvmbr Automation

## 한 줄 설명

엑셀로 관리하던 반복 업무를 웹 관리자 화면에서 자동으로 처리해주는 맞춤 자동화 제작 서비스.

## 대상 고객

- 스마트스토어 / 쿠팡 / 카페24 운영자
- 쇼핑몰 MD
- 온라인 판매 대행자
- 소규모 사업자
- 반복 입력 업무가 많은 운영 담당자

## 해결하는 문제

- 엑셀 데이터를 보고 웹 관리자에 하나씩 입력해야 한다.
- 상품 가격, 재고, 옵션, 상태 변경 작업이 반복된다.
- 실수 가능성이 높다.
- 단순 반복 작업에 시간이 많이 든다.

## 제공 서비스

고객의 실제 업무 흐름에 맞춰 자동화 스크립트 또는 실행 프로그램을 제작한다.

예시:

- 엑셀 상품 목록 기반 가격 수정
- 재고 수량 일괄 변경
- 상품 상태 변경
- 옵션명/옵션가 수정
- 반복 검색 후 저장
- 작업 성공/실패 결과 리포트 생성

## 기본 흐름

1. 고객이 엑셀 양식과 작업 화면 설명을 제공한다.
2. 반복 업무 절차를 정리한다.
3. 샘플 데이터로 자동화 프로토타입을 제작한다.
4. 고객이 테스트한다.
5. 수정 후 납품한다.
6. 필요 시 유지보수를 제공한다.

## 가격 초안

- 간단한 자동화: 10만 원 ~ 30만 원
- 중간 난이도 자동화: 30만 원 ~ 70만 원
- 복잡한 자동화: 70만 원 이상
- 유지보수: 월 5만 원 ~ 20만 원

## 차별점

- 클라우드 업로드 없이 로컬에서 실행 가능
- 고객의 실제 엑셀 양식에 맞춤 제작
- 반복 입력, 수정, 저장, 대기, 결과 기록까지 처리
- 개발자가 아닌 운영자도 실행할 수 있는 형태로 제공

## 첫 MVP

스마트스토어/쇼핑몰 관리자 기준:

엑셀 파일을 읽고  
상품코드로 검색한 뒤  
가격 또는 재고를 수정하고  
성공/실패 결과를 엑셀로 저장하는 자동화 데모.
